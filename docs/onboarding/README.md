# Onboarding Research Notes

This folder contains implementation-oriented onboarding material for Hermes.

- `hermes-core-architecture-report.md`: guided narrative of the core agent architecture.
- `hermes-core-architecture-notes.md`: source map and detailed implementation notes for follow-up reading.
- `hermes-platform-template-guide.md`: reusable blueprint for porting the
  Hermes architecture to other languages and applying it to niche applications.

These notes were prepared from the codebase on branch
`tmatow4/hermes-core-architecture-research`.
